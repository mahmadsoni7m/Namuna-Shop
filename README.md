# NAMUNA SHOP

Мағозаи онлайнии либос бо ранги сиёҳ ва тиллоӣ. Сайти статикӣ аст (HTML, CSS, JavaScript) — сервер ва базаи маълумот лозим нест. Дар **GitHub Pages** ва **Netlify** кор мекунад.

Фармоиш тавассути **Telegram** ё **WhatsApp** фиристода мешавад.

---

## 1. Сохтори файлҳо

```
Namuna-Shop/
├── index.html          — саҳифаи асосӣ
├── catalog.html        — каталог
├── product.html        — саҳифаи маҳсулот
├── favorites.html      — дӯстдоштаҳо
├── cart.html           — сабад
├── checkout.html       — расмикунонии фармоиш
├── 404.html            — саҳифаи хато
├── config.js           — танзимот (Telegram, WhatsApp, Instagram)
├── manifest.json       — барои насби сайт ҳамчун барнома (PWA)
├── service-worker.js   — кори офлайн
├── css/                — услубҳо
├── js/
│   └── products.js     — РӮЙХАТИ МАҲСУЛОТ (асосан инро таҳрир мекунед)
└── assets/
    ├── products/       — расмҳои маҳсулот
    ├── banners/        — баннерҳо
    ├── icons/          — нишонаҳои барнома
    └── logo/           — логотип
```

---

## 2. Тағйир додани танзимот (Telegram / WhatsApp)

Файли `config.js`-ро кушоед:

```js
telegramUsername: "namuna_shop",   // номи корбар, бе @
whatsappNumber: "992900000000",    // бо рамзи кишвар, бе +
instagramUsername: "namuna_shop"   // бе @
```

- Агар холӣ гузоред, сайт вайрон намешавад: пайвандҳои иҷтимоӣ танҳо огоҳӣ нишон медиҳанд.
- Пас аз пур кардан, тугмаҳои «Telegram» ва «WhatsApp» дар саҳифаи фармоиш ба шумо мефиристанд.

---

## 3. Илова кардани маҳсулот дастӣ (агар admin.html истифода набаред)

1. Файли `js/products.js`-ро кушоед.
2. Дар рӯйхати `PRODUCTS` як блоки мавҷударо нусха кунед ва ба охири рӯйхат гузоред.
3. Қиматҳоро иваз кунед:

| Майдон | Маъно |
|---|---|
| `id` | рақами ягона (барои ҳар маҳсулот фарқ кунад) |
| `name` | ном |
| `category` | `"Мардона"`, `"Занона"` ё `"Аксессуарҳо"` |
| `price` | нарх (сомонӣ) |
| `oldPrice` | нархи пештара (барои тахфиф; агар набошад, хат занед ё нависед) |
| `description` | тавсиф |
| `colors` | рангҳо ва расмҳои онҳо |
| `sizes` | андозаҳо, масалан `["S","M","L","XL"]` |
| `soldOutSizes` | андозаҳое, ки тамом шудаанд |
| `hot` / `limited` / `sale` | нишонаҳо: «Оммавӣ», «Маҳдуд», «Тахфиф» (`sale` бе `oldPrice` кор намекунад) |

## 3б. Идоракунии маҳсулот аз телефон (admin.html)

Саҳифаи `admin.html` ба шумо имкон медиҳад маҳсулотро **илова**, **таҳрир** (нарх, ном, андоза, нишонаҳо), ранги нав илова ва **нест** кунед. Тағйирот бевосита ба GitHub навишта мешавад.

**Як бор (Token сохтан):**
1. github.com → акси профил → **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
2. Repository access: **Only select repositories** → репозиторийи сайтро интихоб кунед.
3. Permissions → **Contents: Read and write**.
4. Token-ро нусха кунед (дубора нишон дода намешавад).

**Ҳар дафъа:**
1. `https://<корбар>.github.io/<репозиторий>/admin.html`-ро кушоед.
2. Дар қисми 1 репозиторий (`корбар/ном`) ва token-ро гузоред → «Захира ва санҷиш».
3. Қисми 2: маҳсулоти нав. Қисми 3: рӯйхат бо тугмаҳои «Таҳрир» ва «Нест».
4. Баъд аз 1–2 дақиқа маҳсулот дар сайт пайдо мешавад.

Token-и худро ба касе надиҳед. Агар гум шуд, онро дар GitHub нест кунед.

## 4. Илова кардани расмҳо

Расмҳо дар ин ҷой нигоҳ дошта мешаванд:

```
assets/products/product-001/black/1.jpg
assets/products/product-001/black/2.jpg
assets/products/product-001/white/1.jpg
```

Қоида: `product-<рақами 3-рақама>/<ранг бо ҳарфи лотинӣ>/<рақам>.jpg`

1. Папкаи нав созед, масалан `product-011/black/`.
2. Расмҳоро `1.jpg`, `2.jpg`, `3.jpg` ном диҳед.
3. Дар `products.js` дар майдони `images` роҳҳоро нависед.

Тавсия: расм квадрат ё 4:5, андозааш то 200–300 КБ (то сайт зуд кушода шавад).

> Сайт бе маҳсулот оғоз мешавад. Расмҳои баннер (`assets/banners`) намунавӣ мебошанд; онҳоро бо расмҳои худатон иваз кунед (номи файл бетағйир).

---

## 5. Тағйир додани нарх, ранг ва андоза

- **Нарх:** дар `products.js` майдони `price`-ро тағйир диҳед.
- **Андоза:** майдони `sizes`-ро тағйир диҳед.
- **Ранги нав:** дар аввали `products.js` ба `COLOR_HEX` як сатр илова кунед:
  ```js
  "Зард": "#e0b400",
  ```
  Сипас номи ранг (`"Зард"`) ва папкаи он (`yellow`) дар маҳсулот истифода мешавад.
- **Тағйири ранги сайт:** `css/style.css`, дар аввал, қисми `:root`.

---

## 6. Гузоштани сайт дар GitHub Pages

1. Дар github.com ҳисоб кушоед ва репозиторийи нав созед (масалан `namuna-shop`), **Public**.
2. Ҳамаи файлҳоро (мундариҷаи папкаи `Namuna-Shop`) боргирӣ кунед.
   - Агар файлҳо зиёданд, бо **Termux**: `git init`, `git add .`, `git commit -m "start"`, `git remote add origin ...`, `git push -u origin main`.
3. Дар репозиторий: **Settings → Pages → Branch: main / (root) → Save**.
4. Баъд аз 1–2 дақиқа сайт дар ин суроға мекушояд:
   `https://<номи-корбар>.github.io/<номи-репозиторий>/`

Ҳамаи роҳҳо нисбӣ мебошанд, бинобар ин тағйири иловагӣ лозим нест.

### Netlify
Ба netlify.com даромада, папка ё zip-ро ба саҳифаи **Deploy** кашед. Тамом.

## 7. Таҳрир аз телефони Android (Acode)

1. Acode-ро аз Google Play ё F-Droid насб кунед.
2. Zip-ро бо ZArchiver (ё дигар барнома) кушоед.
3. Дар Acode: **Open folder** → папкаи `Namuna-Shop`-ро интихоб кунед.
4. `js/products.js` ё `config.js`-ро кушоед, тағйир диҳед ва захира кунед (дискет).
5. Барои дидан: файли `index.html`-ро дар Acode бо тугмаи **Run** (пешнамоиш) кушоед.
6. Баъд файлҳоро ба GitHub боргирӣ кунед (тавассути браузер ё Termux).

Нукта: баъзан барои дидани тағйирот саҳифаро аз нав кушоед (барои кэш).

---

## 8. Насб ҳамчун барнома (PWA)

Дар Chrome-и телефон сайтро кушоед → тугмаи «Насб кардан» ё менюи браузер → **Add to Home screen**. Сайт ҳамчун барнома кушода мешавад ва ҳатто бе интернет (қисман) кор мекунад.

Агар дар `products.js` ё расмҳо тағйирот кунед ва корбарон тағйиротро надиданд, дар `service-worker.js` қимати `VERSION`-ро иваз кунед (масалан `namuna-v2`).

---

## 9. Саволҳои маъмул

**Фармоиш ба куҷо меравад?** Ба Telegram ё WhatsApp-и шумо (ба рақами дар `config.js` навишташуда). Фармоиш дар сервер нигоҳ дошта намешавад.

**Расмҳо намоён нестанд?** Номи папка ва файлро дар `products.js` бо роҳи воқеӣ муқоиса кунед (ҳарфҳои хурд ва калон фарқ мекунанд).

**Сайт холӣ аст?** Хатогиро дар `js/products.js` ҷустуҷӯ кунед (вергул ё қавс фаромӯш шудааст).
